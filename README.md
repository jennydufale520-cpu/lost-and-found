# Lost and Found Website
 A web application built with Django to help people report and claim lost items. Users can browse found items, submit reports, and reconnect lost belongings with their owners.
 ## Features
 - 📋 Report found items with descriptions and photos
 - 🔍 Browse and search for lost items
 - 📱 Responsive design using Bootstrap
 - 📍 Contact form for inquiries
 ## Technologies Used
 - Backend: Django (Python)
 - Frontend HTML, CSS, Bootstrap 5
 - Database: SQLite
 ## How to Run
 ```bash
 # Create virtual environment
 venv\Scripts\activate
 # Install dependencies
 pip install -r requirements.txt
 # Run server
 python manage.py runserver
